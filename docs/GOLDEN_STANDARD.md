# Execution standard

The source release marker is `v4.20.14`. Read [release support](SUPPORT.md)
for platform scope. A source tag does not prove installation acceptance.

Exact host/installation and Git routing, one local intake choice, OS-user
permissions, immutable tasks, durable claims/results, bounded processes,
STOP, inherited leases, UNKNOWN/no replay and independent rollback are
mandatory. Projects are optional. Mac's parallel worker cap is four and
repository tasks remain serialized per repository.

Reuse the established runtime and preserve owner files. GUI/browser prototypes
are frozen. There is no cross-host scheduler or automatic machine selection.
A new customer installation must pass real native service and Git checks.
